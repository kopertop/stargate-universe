# sprites/

Source 2D art. `ui/items/*.png` are the 1.2k px inventory icon masters; the game loads the 160 px copies in `assets/items/`
(regenerate with `sips -Z 160`). `portraits/` are crew portraits for a future dialogue UI. `ui/minigames/door_hack_concept.png`
is the reference for `src/hotwire.js`.
