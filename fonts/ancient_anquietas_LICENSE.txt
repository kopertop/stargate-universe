Anquietas (Regular) — "the language of the Ancients"
====================================================

File:      ancient_anquietas.ttf
Typeface:  Anquietas Regular
Author:    Joseph Spicer (2004)
Embedded copyright string: "Copyright (c) Joseph Spicer, 2004. All rights reserved."

Source obtained:
  https://raw.githubusercontent.com/mouuff/Stargate-Languages-Translator/master/assets/fonts/anquietas.ttf
  (mirrored in several fan archives, e.g. ffonts.net as "sg_anq.ttf").

What it is:
  A fan-made glyph font that maps the Latin alphabet (A-Z, a-z, 0-9, and
  common punctuation) one-to-one onto the on-screen "Ancient"/Lantean glyph
  set from the Stargate franchise. Because the mapping is 1:1 and
  deterministic, rendering ordinary English text in this font produces a
  consistent visual substitution cipher (the same word always yields the
  same glyphs) — which is exactly what the room "decipher" feature wants.
