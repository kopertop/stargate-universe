# Stargate Universe — Destiny (browser game)

Standalone Three.js game; no build step for dev. Read `CLAUDE.md` first, then the local `AGENTS.md` of any directory you
enter. Use tabs, `const`, arrow functions, async/await; keep files small and data-driven (`data/*.json` drives the ship,
chapters and items). Every non-obvious lesson goes in `.ai/learnings/<lesson>.md` (one per file).
